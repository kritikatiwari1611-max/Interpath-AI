# InternPath AI - 5-Minute Viva Demo Script

## Minute 1: Introduction & Landing Page
- Open `http://localhost:5000` in the browser.
- "Good morning respected examiners. This is **InternPath AI** — an end-to-end career readiness platform for undergraduate students."
- Point out:
  - Hero banner: "Your Skills. Your Roadmap. Your Internship."
  - "Demo Mode Active" badge indicating transparent offline operation.
  - Three-step "How it works" summary.
  - One-click demo login buttons.

## Minute 2: Scenario (b) - Technical Student Flow (BCA -> Python Developer)
- Click "Student (BCA)" quick fill (`student@demo.com` / `Student@123`) and log in.
- Show Dashboard:
  - Welcome banner highlighting BCA 6th Semester.
  - Target role: Python Developer.
  - Deterministic Readiness Score bar.
- Open **Skill Gap Analysis** from the three-dot (⋮) menu:
  - Point out that Python, SQL, and Flask have been analyzed.
  - Show the missing skills (e.g. Unit Testing) and priority action callout.
- Open **My Roadmap**:
  - Show the 4 stages (Foundation -> Practice -> Project -> Interview).
  - Toggle a task status from "Pending" to "Completed" and show the progress bar update automatically.

## Minute 3: Scenario (c) - Non-Technical Student Flow (B.Com -> Finance)
- Click Logout, then log in as `priya@demo.com` (`Student@123`).
- Navigate to **Internship Roles**:
  - Show that Priya's target role is **Finance Analyst**.
- Navigate to **Skill Gap Analysis**:
  - **Key Viva Defense Point:** Notice that for a Commerce/Finance student, **there are zero programming requirements**.
  - Required skills evaluate Financial Statement Analysis, Excel & Advanced Formulas, and Valuation.
- Open **Project Recommendations**:
  - Projects display "Equity Research Model of Tech Sector" rather than coding repositories.

## Minute 4: Scenario (e) - Mock Interview Simulation
- Open **Interview Preparation** page.
- Explain the Question Bank filters (Role, Category, Difficulty).
- Under "Simulate a Real-Time Mock Interview", choose Python Developer and click **Start Mock Interview**.
- Answer Question 1:
  - For an MCQ, select an option and click Submit. Show the immediate rule-based feedback and explanation.
  - For a written question, type an answer with an example. Show the keyword analysis and constructive critique ("Rule-based feedback, not AI evaluation").
- Complete the session to display the final score, accuracy %, and weak topics summary. Show how this updates the interview stats.

## Minute 5: Deterministic Readiness Score & Explainability
- Navigate to **Internship Readiness Score**:
  - Explain the 5 weighted components: Skills (35%), Projects (25%), Resume (15%), Interview (20%), Certifications (5%).
  - Highlight the disclaimer: *"This score estimates preparation. It does not guarantee selection."*
  - Switch the tips language to "हिंदी / Hinglish" to show multilingual coaching.
- Open **Settings** -> Click **Download / Print Career Report** to show the printable report view.
- Conclude: "InternPath AI bridges coursework to workplace readiness with 100% explainable algorithms and offline resilience. Thank you!"
